# Суммарные открытия разделов (без Google Analytics)

Firestore → Data → section_counts → документ YYYY-MM-DD (UTC). Поля home, globe, library — суммарное число открытий; отсутствующее поле означает 0. Отчёты в приложение не встроены.

Считаются только открытия авторизованными онлайн-пользователями, с момента включения правил. При первом входе на страницу и переходе между вкладками — одно открытие, при каждом открытии общего глобуса — одно. Повторное нажатие активной вкладки и перерисовки не считаются; личная карта библиотеки не считается глобусом. Возврат после закрытия глобуса на ту же вкладку не считается новым открытием. Гости и пропущенные/отклонённые записи не учитываются. Это приблизительные открытия, не уникальные люди. Нет новых cookies, идентификаторов, журналов событий, чтения Библии или внешней системы аналитики. Обычная авторизация Firebase применяется к запросу записи; инфраструктурные журналы могут существовать отдельно. 

## Доступ и запуск
- Клиентам запрещены get/list/delete, разрешено только увеличение одного счётчика на 1 для текущего дня. Клиентские записи не защищены от искусственного накручивания авторизованным пользователем; для строгого контроля нужна серверная функция.
- Firebase Console использует IAM: проверить Project settings → Users and permissions и оставить доступ к Firestore только нужным администраторам. Правила Firestore не ограничивают пользователей с привилегиями IAM.
- До включения обновить уведомление о конфиденциальности: приложение сохраняет суммарное число открытий трёх разделов по дням в Firebase; отчёты доступны владельцу, идентификаторы посетителей в счётчике не хранятся. Проверить правовое основание и необходимость согласия по применимому законодательству.
- Опубликовать только дополнительный блок match /section_counts/{day} из firestore.rules в существующих активных правилах. Не заменять действующие правила целиком, если они отличаются.
- После публикации открыть разделы и проверить документ текущей даты в Firebase Console; через обычный клиент документ прочитать нельзя.
- Для отключения удалить блок из активных правил и код; при необходимости удалить коллекцию через консоль. Не удалять другие коллекции.
